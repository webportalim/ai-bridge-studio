# AI Bridge Companion — Browser Extension V1

Connects Chrome and Microsoft Edge browsers directly to **AI Bridge Desktop V1** via a secure localhost-only HTTP bridge. Enables sending active ChatGPT web discussions directly into the Desktop orchestrator for automated bug fixing and code generation.

---

## 🔒 Security & Privacy Guarantees

- **100% Localhost**: All communications are bound strictly to `127.0.0.1` and never contact any external server.
- **Zero Credentials / Zero Tokens**: The extension **NEVER** reads, stores, or accesses cookies, session tokens, authorization headers, or login credentials.
- **One-Time Pairing Code**: Authentication uses a 6-digit code generated by AI Bridge Desktop, which exchanges a cryptographically random token saved in browser local storage.
- **No API Keys**: Leverages your existing authenticated browser sessions without consuming OpenAI or Anthropic API credits.

---

## 🛠 Installation Instructions

### Google Chrome
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** (Paketlenmemiş öğe yükle) in the top-left corner.
4. Select the directory:
   ```
   F:\AI-Bridge\browser-extension
   ```
5. Pin the **AI Bridge Companion** icon to your browser toolbar.

### Microsoft Edge
1. Open Microsoft Edge and navigate to `edge://extensions/`.
2. In the left sidebar, turn on **Developer mode**.
3. Click **Load unpacked** (Paketlenmemişi yükle).
4. Select the directory:
   ```
   F:\AI-Bridge\browser-extension
   ```
5. Pin the extension to your toolbar.

---

## 🚀 Pairing & Usage

1. Launch **AI Bridge Desktop**.
2. On the **Run** screen under **Chat Context**, click **Pair Extension** (or open Settings).
3. A 6-digit pairing code will appear (valid for 5 minutes).
4. Click the **AI Bridge Companion** extension icon in your browser toolbar.
5. Enter the 6-digit pairing code and click **Connect to Desktop**.
6. Navigate to any active conversation on [chatgpt.com](https://chatgpt.com).
7. Open the extension popup; it will automatically detect the discussion title, message count, and character size.
8. Click **Send Current Chat to AI Bridge**.
9. The Desktop Chat Context card will immediately update with the discussion details and pass `--context-file` to `ai_bridge.sh` on your next run!
